Add Grok to the supported coding-agent integrations. `openwiki integrations install grok` installs the OpenWiki skill under `.grok/skills/openwiki` and a managed `[mcp_servers.openwiki]` block in `~/.grok/config.toml` (user scope) or `.grok/config.toml` (project scope), so Grok can drive the same five-operation MCP page-job lifecycle as Codex, Claude Code, and OpenCode.
